SUBTITLE EDITING PORTFOLIO

文字起こしから字幕デザインまで、
Claude Code で仕上げた字幕編集

音声の文字起こし、固有名詞の校正、日英翻訳、ニュース風テロップのデザイン、動画への焼き込みまでを、Claude Code とフリー素材だけで制作しました。

制作物

日本語字幕・ニュース風テロップ(濃紺の帯に白文字)

YouTube で見る: 日本語版 / English version

字幕が二重に見える場合: YouTube の自動字幕が表示されています。動画右下の字幕ボタン(CC)を押すとオフにできます。
If you see extra captions, they are YouTube's auto-generated captions. Turn them off with the CC button at the bottom right of the player.

字幕スタイル: 濃紺の半透明の帯に白文字。背景が明るくても読みやすく、報道番組のテロップに近い見た目にしています。

素材: 岸田総理 フィリピン・マレーシア訪問についての会見(約1分54秒) / 1280×720

制作工程

  1. 素材の選定とライセンス確認商用利用できる CC BY の公式動画を選び、出典とライセンスを記録。webm は ffmpeg で mp4(H.264/AAC)に変換。
  2. 文字起こしfaster-whisper(medium)で音声を認識し、SRT を生成。
  3. 校正固有名詞や専門用語の認識ミスを文脈から修正し、公式発言録と照合して確認。
  4. 翻訳校正済みの日本語を英訳。元の発言の区切りに合わせて時間割りを維持。
  5. 字幕デザインと分割1行24文字(英語は約58文字)以内に句読点で区切り、文字数に応じて表示時間を按分。ASS 形式でスタイルを定義。
  6. 焼き込みと確認ffmpeg で映像に字幕を焼き込み、フレームを書き出して見切れや欠けがないか確認。

校正の例

音声認識の誤りを文脈から直した主な箇所です。

認識結果フィニッグとマレーシア → フィリピンとマレーシア
認識結果人国間関係 → 二国間関係
認識結果本部試合に基づく → 法の支配に基づく
認識結果日朝や独立首脳会議 → 日・ASEAN特別首脳会議
